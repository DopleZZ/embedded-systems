# Fitocube Frontend

Фронтенд приложение для платформы Fitocube на React.

## Требования

- Node.js 18+ и npm
- Бэкенд должен быть запущен на `http://localhost:8080`

## Быстрый старт

1. Установите зависимости:
```bash
cd frontend
npm install
```

2. Запустите dev-сервер:
```bash
npm run dev
```

3. Откройте браузер:
```
http://localhost:3000
```

## Функционал

- 🌱 **Растения**: просмотр, детальная информация, полив, автополив
- 👥 **Друзья**: список друзей, запросы в друзья
- 🎮 **Игры**: батлы настроения, недельный челлендж
- 📊 **Статистика**: достижения и награды
- 🔐 **Авторизация**: регистрация и вход

## Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## Структура проекта

- `src/pages/` - страницы приложения
- `src/components/` - переиспользуемые компоненты
- `src/api/` - API клиент для работы с бэкендом
- `src/context/` - контекст для управления состоянием

## API

Приложение использует все эндпоинты из OpenAPI спецификации:
- `/auth/*` - авторизация
- `/plants/*` - управление растениями
- `/friends/*` - управление друзьями
- `/games/*` - мини-игры
- `/stats/*` - статистика
